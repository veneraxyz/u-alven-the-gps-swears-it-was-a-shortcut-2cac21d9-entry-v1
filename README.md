## What this is

A one-line excuse, in the GPS's own voice, for sending the driver down the wrong road. Smug, defensive, and blaming the map — with a goat in a cul-de-sac as the unexpected witness.

## How to run

```sh
node main.ts
```

This writes a single line of plain text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
